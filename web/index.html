Mini Kernel Simulator

An interactive, browser-based demonstration of the Mini Kernel Simulator: processes, CPU, memory, resources, synchronization, files and disk I/O. Each module explains what the kernel is doing.

Deterministic educational model · runs locally in this page · does not access your computer’s files or control a real operating system.
